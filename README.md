# User Management System

A simple user management web application built with HTML, CSS, and JavaScript.

## Features

- Add users
- Edit users
- Delete users
- Display user information
- Simple and responsive interface

## Technologies

- HTML
- CSS
- JavaScript

## Purpose

This project was built to practice JavaScript, DOM manipulation, events, and basic data handling.
